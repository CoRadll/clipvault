# clipvault

Windows 剪贴板历史管理器。

> 状态：初始化中，尚未发布。

## 它解决什么

复制一段代码，再复制别的东西，前一段就没了。clipvault 常驻后台记录剪贴板历史，
按全局热键唤起一个置顶列表，输入几个字过滤，回车把选中的内容写回剪贴板。

## 功能

- [ ] 监听剪贴板变化并持久化
- [ ] 全局热键唤出无边框置顶浮层
- [ ] 关键词过滤
- [ ] 回车写回剪贴板
- [ ] 历史上限 100 条，超限按最近使用淘汰
- [ ] 托盘图标与退出入口

## 当前范围

只处理**文本**剪贴板。单条超过 2 MB 的内容静默忽略。图片与文件类型暂不支持。
